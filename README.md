# وِكاد — ركن ضيافة القهوة
# Wekad — Coffee Catering Counter

موقع حجز خدمات كيترنق القهوة. العميل يختار الخدمة، ثم عدد الأكواب، ثم عدد الأيام،
ثم يحدد إن كان الحجز باسم شركة أو باسمه الشخصي — وينتهي بإرسال الطلب كاملاً
على واتساب.

---

## التشغيل

الموقع **ملفات ثابتة فقط**: لا يحتاج قاعدة بيانات ولا سيرفر ولا تنصيب أي شيء.

**للمعاينة على جهازك:**

```bash
npx --yes serve -l 4173 ~/Desktop/wekad
```

ثم افتح `http://localhost:4173`.

**للنشر:** ارفع محتويات المجلد كما هو على أي استضافة —
Netlify أو Vercel أو GitHub Pages أو أي استضافة cPanel عادية. ما فيه خطوة بناء.

---

## مسار الحجز

```
1. الخدمة            →  ركن ضيافة القهوة  |  خدمة الحافظات
2. الحجم             →  ٢٥ / ٥٠ / ١٠٠ / ٢٠٠ / ٣٠٠ كوب   (أو حافظة / حافظتين)
3. الحلى والإضافات   →  كميات مفتوحة لكل صنف (باريستا، طباعة أكواب، ١٣ صنف حلى)
4. الموعد والموقع    →  الأيام، التاريخ، الوقت، المدينة، الحي + تحديد على الخريطة
5. بياناتك           →  شركة أو أفراد + الاسم والجوال (+ اسم الشركة والرقم الضريبي)
6. التأكيد           →  مراجعة الطلب ثم زر "تأكيد الطلب"
```

الإجمالي يُحسب مباشرة وأنت تختار ويظهر أسفل النموذج طوال الوقت.
بعد التأكيد يظهر للعميل **رقم طلب** ورسالة تأكيد، ويصلك الطلب كرسالة منسّقة
على الرقم **‎055 2487 363**.

### الكميات

كل صنف — باريستا أو حلى — له عدّاد مستقل، يعني العميل يقدر يطلب باريستا أو
اثنتين أو ثلاث، ويحدد عدد القطع من كل صنف حلى.

- **باريستا:** السعر لكل باريستا **في اليوم** — ٣٠٠ × العدد × عدد الأيام.
- **طباعة أكواب:** السعر لكل كوب، يُطلب بخطوات من ٢٥.
- **الحلى:** السعر لكل قطعة، تُطلب بخطوات من ١٠.

### تحديد الموقع

العميل يختار المدينة (**المنطقة الشرقية فقط**) ويكتب الحي، ثم يحدد المكان بدقة
على خريطة تفاعلية — إما بسحب الدبوس أو بالضغط على الخريطة أو بزر
"موقعي الحالي". يصلك رابط خرائط Google جاهز مع الطلب.

الخريطة تعتمد على Leaflet و OpenStreetMap، بدون أي مفتاح API أو اشتراك.
لو تعذّر تحميلها لأي سبب، يظهر للعميل تنبيه ويكمل الطلب بوصف الموقع كتابةً.

## تعديل الأسعار والباقات

كل البيانات في أعلى ملف [assets/js/app.js](assets/js/app.js) — عدّل الأرقام واحفظ، خلاص:

```js
const WHATSAPP = '966552487363';        // رقم استقبال الطلبات

const PACKAGES = [ … ];                  // باقات ركن القهوة
const FLASKS   = [ … ];                  // خدمة الحافظات

const EXTRAS = [                         // الإضافات (كمية مفتوحة لكل صنف)
  { id:'barista', price:300, per:'day',   step:1,  max:10   },
  { id:'print',   price:5,   per:'piece', step:25, max:3000 },
];

const DESSERTS = [ … ];                  // ١٣ صنف حلى، السعر لكل قطعة
const DESSERT_STEP = 10;                 // خطوة الزيادة في عدد القطع

const CITIES     = [ … ];                // مدن المنطقة الشرقية
const MAP_CENTER = [26.4207, 50.0888];   // مركز الخريطة الافتراضي
```

- `per: 'day'` → السعر × الكمية × عدد الأيام.
- `per: 'piece'` → السعر × الكمية (مرة واحدة).
- `step` → مقدار الزيادة عند الضغط على `+`.

> ⚠️ **أسعار الحلى الحالية مبدئية** وضعتها كقيم افتراضية —
> بدّلها بأسعارك الحقيقية في مصفوفة `DESSERTS`.

لتغيير رقم الاستقبال: عدّل `WHATSAPP` في الملف أعلاه، وكذلك الروابط
في [index.html](index.html) (ابحث عن `966552487363`).

الرسالة مقسّمة لأقسام مرقّمة بعناوين عريضة ونقاط، عشان تُقرأ بسرعة على الجوال:

```

رقم الطلب: WK-K4M2Q

━━━━━━━━━━━━━━━
١ · الخدمة المطلوبة
━━━━━━━━━━━━━━━
▪︎ النوع: ركن ضيافة القهوة
▪︎ الباقة: 200 كوب
▪︎ عدد الأيام: 2 أيام
▪︎ السعر: 3,900 × 2 = 7,800 ر.س

━━━━━━━━━━━━━━━
٢ · الموعد        ← اليوم، التاريخ، وقت الحضور
٣ · الموقع        ← المدينة، الحي، الوصف، رابط الخريطة
٤ · الإضافات      ← كل صنف بعدده وسعره ومجموعه
٥ · الحلى         ← كل صنف بعدده وسعره ومجموعه
٦ · بيانات العميل ← الاسم، الجوال، شركة/أفراد، الرقم الضريبي
٧ · ملاحظات العميل

━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━

▪︎ الحلى: 300 ر.س

الإجمالي التقديري: 9,300 ر.س
غير شامل ضريبة القيمة المضافة
```

شكل الرسالة كامل في دالة `buildMessage()` داخل [app.js](assets/js/app.js).

| `motif.svg` | زخرفة النخلة/النجمة — vector |

الشعار والزخرفة **vector**، يعني يطلعون واضحين على أي حجم شاشة.

## إضافة صورك

ارمِ الصور الجديدة في `assets/img/` وبدّل المسارات في [index.html](index.html):

- صورة القسم التعريفي: ابحث عن `assets/img/counter.jpg` داخل `<figure class="about-figure">`
- الشريط العريض: نفس الاسم داخل `<section class="strip">`
- خلفية الغلاف: في [style.css](assets/css/style.css) عند `.hero-bg`

لو عندك صور أكثر وتبي معرض صور كامل، قل لي وأضيفه.

## ملاحظات

- الأسعار المعروضة **غير شاملة الضريبة**، والنص تحت نموذج الحجز يوضّح ذلك.
- المدن المتاحة **المنطقة الشرقية فقط** — القائمة في `CITIES`.
- لا تُحفظ أي بيانات عميل في أي مكان — كل شيء يتم في متصفح العميل ثم يُرسل لواتساب.
- الموقع يشتغل على الجوال والكمبيوتر، وباتجاه RTL كامل.
- الخريطة تحتاج اتصال إنترنت (Leaflet + OpenStreetMap من CDN).
- يحترم إعداد `prefers-reduced-motion` لمن يفضّل تقليل الحركة.
